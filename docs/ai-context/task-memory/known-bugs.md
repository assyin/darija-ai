## Recurring patterns to watch

These aren't bugs yet, but they've caused issues before:

- **RTL text direction in mixed content**: Arabic + Latin tech terms in the same element can flip direction. Use `<bdi>` wrapper. Previously caused display issues in article cards.
- **GPT Arabic output corruption**: In cross-model testing, GPT-4o-mini produced reverse-RTL strings in the `suggested_fix` field. Reason cross-model pipeline is NOT in prod (ADR-002).
- **Alembic autogenerate false positives**: SQLModel sometimes generates spurious migrations for unchanged tables. Always review autogenerated migration before applying.
- **asyncio fixture scope warnings**: Fixed with `asyncio_default_fixture_loop_scope = "session"` (added 2026-05-06). May resurface if new test files don't inherit the config.
