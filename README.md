## 🚀 Quick start

```bash
# First-time setup
make setup

# Run dev environment
make dev
```

## 📁 Structure

- `backend/` — FastAPI + worker (Python 3.12)
- `frontend/` — Next.js 15 (TypeScript)
- `shared/` — Shared OpenAPI types (generated)
- `infra/` — Docker compose, deployment configs
- `docs/` — Architecture decisions, prompts, glossary
